## 📦 Instalación local

> Despues de clonar el proyecto se ejecutan los siguientes pasos
 
 1. Instalacion de dependencias

 Ingresa a la carpeta Frontend y ejecuta  `npm i`, una vez instaladas las dependencias pasamos al siguiente punto.

 2. Creacion de archivos .env

En la raiz del proyecto creamos el archivo .env con los comandos linux `touch .env`, en windows `echo. > .env`
